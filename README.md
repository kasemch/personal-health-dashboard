# Personal Health Dashboard — Synthetic Demo

Privacy-conscious static demonstration of a health dashboard. **All sample data are synthetic.** Never import real patient records, medications, identifiers, or medical documents into the public GitHub Pages instance.

## Features
- Color-coded lipid and kidney function charts
- Searchable, date-filtered laboratory table
- CSV/JSON import and export for synthetic records
- Medication reconciliation demonstration
- Browser print / Save as PDF
- Experimental browser-local AES-256-GCM encrypted storage and encrypted backup

## Deployment safety
This package is for a public **synthetic-data demonstration only**. The static page is delivered from GitHub Pages; browser-local storage is not a substitute for a security review. Avoid real medical information even when encryption is enabled. No analytics or external API endpoints are included.

## GitHub Pages
Repository name: `personal-health-dashboard`
