เว็บไซต์สาธิตบน GitHub Pages: ใช้ข้อมูลสังเคราะห์เท่านั้น ห้ามนำเข้าข้อมูลสุขภาพจริง · ไม่มีการส่งข้อมูลไป API ภายนอก แต่ GitHub Pages เป็นเว็บไซต์สาธารณะ

Medication Reconciliation · ประวัติการจ่ายยา

สถานะปัจจุบันยังไม่ยืนยันทั้งหมด การเลือกสถานะด้านล่างเป็นบันทึกส่วนตัว ไม่ใช่คำสั่งแพทย์

ยาวันที่จ่ายตามภาพคำสั่งตามภาพสถานะที่ผู้ใช้บันทึก

นำเข้าผลตรวจ / บันทึกผลใหม่

นำเข้าไฟล์ JSON ที่ส่งออกจากระบบนี้ หรือ CSV ที่มีหัวคอลัมน์ date,test,value,unit (วันที่ YYYY-MM-DD, ค่าตัวเลขเท่านั้น) ตรวจข้อมูลก่อนนำเข้า ไม่มีการอ่าน PDF/ภาพอัตโนมัติ

ข้อมูลใหม่เก็บในหน่วยความจำระหว่างเปิดหน้านี้เท่านั้น เว้นแต่เลือกบันทึกในเบราว์เซอร์

แผนติดตามสุขภาพ

โปรดหารือกับแพทย์เรื่องรายการยาปัจจุบัน ความดันโลหิต ผลเลือด และการตรวจติดตามตามข้อบ่งชี้ ไม่มีการสร้างคำแนะนำเฉพาะบุคคลจากข้อมูลสาธิต

ส่งออก Medical Record PDF

ปุ่มนี้เปิดหน้าพิมพ์ของเบราว์เซอร์ เลือก “Save as PDF / บันทึกเป็น PDF” ได้โดยไม่ส่งข้อมูลออกไปยังเว็บไซต์อื่น ตัวเอกสารรวมตารางผลตรวจที่กรองอยู่และกราฟปัจจุบัน (ตรวจตัวกรองก่อนพิมพ์)

แอปสาธิตที่ไม่มีข้อมูลผู้ป่วยจริง · ไม่ได้เชื่อมต่อระบบโรงพยาบาล
